# WarionAI (Android app)

Original UI, built to talk to the Warion AI engine (see the other zip) for
ball-tracking DRS. No login, no cloud storage - deliveries save to the
phone's own gallery. See NEXT_STEPS.md for what's implemented, what's not
yet tested, and honest gaps.

Quickest path to an APK: push this to GitHub, the included Action builds
one for you. See NEXT_STEPS.md.
